# Black Damagochi 🖤

바탕화면 위에서 살아가는 픽셀 아트 데스크탑 펫

상사 때문에 직장 스트레스받는 친구를 위해 만들었습니다. 🖤

---

## 설치

[Releases](https://github.com/juheeNam/black_damagochi/releases) 페이지에서 운영체제에 맞는 설치 파일을 다운받아 실행하세요.

| 운영체제 | 파일 |
|----------|------|
| Windows | `black-damagochi_x.x.x_x64-setup.exe` |
| macOS (Intel) | `black-damagochi_x.x.x_x64.dmg` |
| macOS (Apple Silicon) | `black-damagochi_x.x.x_aarch64.dmg` |
| Linux | `black-damagochi_x.x.x_amd64.AppImage` |

> **v0.1.1 이상** 설치 시 앱 실행 중 새 버전이 감지되면 자동으로 업데이트 안내가 표시됩니다.

---

## 조작법

| 동작 | 효과 |
|------|------|
| **캐릭터 클릭** | 아파합니다 (기분 ↓) |
| **캐릭터 우클릭** | 하트를 충전해줍니다 (기분 ↑) |
| **캐릭터 드래그** | 창을 이동합니다. 어지러워해요 |
| **3초 이상 드래그 후 드랍** | 화를 냅니다 |
| **1 / 2 / 3 키** | 종이 / 볼펜 / 슬리퍼 던지기 모드 |
| **Ctrl+L** | 방해금지 모드 토글 |
| **Escape** | 앱 종료 |

---

## 상태

| 상태 | 조건 |
|------|------|
| 기본 (idle) | 평소. 위아래로 둥실거려요 |
| 어지러움 (dizzy) | 드래그 중 |
| 맞음 (hit) | 클릭 / 우클릭 직후 |
| 화남 (angry) | 기분이 30 이하이거나 오래 흔든 뒤 |
| 축 처짐 (down) | 기분이 매우 낮을 때 |
| 심부름 중 (quest) | 심부름 진행 중 |

---

## 기분 게이지 (♥)

캐릭터 위에 마우스를 올리면 게이지가 표시됩니다.

- 🟢 초록 — 기분 좋음
- 🟠 주황 — 기분 보통
- 🔴 빨강 — 기분 나쁨 (화난 상태로 전환)

기분은 시간이 지나면 자동으로 조금씩 떨어지니, 가끔 우클릭으로 충전해주세요.

---

## 레벨 & 경험치 (⭐)

심부름을 완료하면 경험치(EXP)를 획득합니다. 레벨이 오르면 새로운 스킬이 해금됩니다.

---

## 심부름 📋

설정 → **심부름** 버튼으로 열 수 있습니다.

- 심부름을 선택하면 일정 시간 후 완료
- 완료 후 **수령하기** 버튼을 눌러 EXP 획득
- 진행 중 취소도 가능

---

## 스킬 ⚡

설정 → **스킬** 버튼으로 확인할 수 있습니다.

- 레벨업 시 자동으로 스킬이 해금됩니다
- 잠긴 스킬은 필요 레벨 달성 시 활성화

---

## 코디 🎨

설정 → **코디** 버튼으로 꾸밀 수 있습니다.

- **스킨** — 캐릭터 전체 색상 변경
- **얼굴** — 선글라스, 안경, 모자, 리본 등 다양한 얼굴 스타일
- **바디** — 넥타이, 하와이안 셔츠, 땡땡이 패턴 등 다양한 의상

---

## 설정 ⚙

캐릭터 위에 마우스를 올리면 표시되는 ⚙ 버튼을 클릭하세요.

| 항목 | 내용 |
|------|------|
| 크기 | S / M / L (스프라이트 크기만 변경, 창 크기는 고정) |
| 투명 | 낮음 / 보통 |
| 숨기기 | 최소화 (작은 버튼으로 축소) |
| 방해금지 | 말풍선·알림 비활성화 |
| 🔊 | 효과음 볼륨 조절 |
| 초기화 | 모든 데이터 리셋 |

---

## 시스템 트레이

작업표시줄 우측 하단 트레이 아이콘을 우클릭하면:

- **자동 시작** — PC 켤 때 자동으로 실행
- **종료** — 앱 종료

> 트레이 아이콘이 안 보이면 `^` 버튼을 눌러 숨겨진 아이콘 영역을 확인하세요.
